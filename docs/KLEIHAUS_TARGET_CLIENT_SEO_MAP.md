## Keyword clusters and routing rules

1. Tier 1 purchase: tiles Kenya/Nairobi, sanitaryware Kenya/Nairobi, kitchen sinks Nairobi, paint suppliers Kenya -> category/location pages.
2. Tier 2 comparison: porcelain vs ceramic, bathroom tiles, tile sizes, sanitaryware selection -> guides -> products.
3. Tier 3 trade/project: contractor suppliers, developer supply, hotel bathrooms, office/school finishes -> `/trade-projects` -> products/projects/contact.
4. Installation/finishing: adhesive, grout, tools, installation support -> `/adhesives-grout`, `/installation-support`.
5. Renovation/planning: tile quantity, bathroom cost, kitchen renovation -> existing guides and calculators only after evidence and QA.
6. Local: Nairobi, Machakos and Makueni -> current hubs; additional counties require delivery/service evidence.
7. Retention: reorder, complementary materials, project phase and maintenance language -> private CRM/owner process first.
8. Authority: case studies, specification guides, genuine supplier resources -> publish only with approved evidence.

## Coverage conclusion

All nine priority segments have at least one existing pathway, led by `/trade-projects`, `/products`, `/sanitaryware`, `/projects` and the three current location hubs. Coverage is present but shallow for product specifications, delivery proof, project evidence, trade terms and post-purchase follow-up. No new audience page is justified until the audience has unique evidence, intent and a materially different conversion path.
