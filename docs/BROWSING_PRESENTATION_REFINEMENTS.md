# Browsing and Presentation Refinements

Implemented from the block review without changing route metadata, APIs, quote submission handlers or WhatsApp navigation.

- Category navigation uses real destination links and route-derived selection rather than highlighting Floor Tiles everywhere. The homepage starts without a selected category.
- Sinks and mixers link to the existing sanitaryware gallery anchor from navigation, category cards and product hub.
- Hero uses a supplied kitchen overview rather than implying an unverified showroom/fleet. Headline and supporting text are shorter; service badges use two columns on mobile. Existing slide movement and controls remain.
- Application cards link to tiles, bathroom tiles and paints with existing category-click analytics.
- Homepage project preview uses an overview, backsplash detail and sink detail. Gallery copy clarifies that images need not represent separate projects.
- Audience cards retain their individual destinations but remove repeated product badges and use specific link labels.
- About preserves vision, mission and values in an expandable section; duplicate benefit badges are removed.
- Sanitaryware's second image block starts with kitchen images and does not duplicate its hero images. The gallery heading now matches its category content. All image files are preserved.
- Category pages omit the redundant generic quote paragraph. Contact instructions are shorter; name, email and phone fields allow appropriate browser autofill without changing validation or payloads.
- The unused calculator remains disabled. Verified specifications, new business promises, customer proof and detailed project attribution still require owner evidence.

The existing overall structure, footer order and contact channels remain. No images were generated, deleted or altered. New browsing regressions complement the existing layout, SEO and analytics tests.
