# Kleihaus SEO Content Roadmap

Date: 2026-07-08

This six-month roadmap is designed to grow topical authority without creating thin duplicate pages. Build pages only when Kleihaus can provide useful, specific guidance, real images, measurements, examples or operational insight. Do not invent projects, reviews, prices or partnerships.

## Publishing Principles

- Prioritize helpful quote-planning content over generic keyword pages.
- Link every new page to a relevant category, guide, location hub and quote/WhatsApp CTA.
- Avoid fixed prices unless the business commits to keeping them accurate.
- Use real customer-approved project evidence only when available.
- Keep Product, Offer, AggregateRating and Review schema out unless the site later has truthful visible content that supports them.

## Internal Link Pattern

Each new guide should include:

- One link to the closest category page.
- One link to the closest guide page.
- One link to a relevant location hub or service-location page.
- One link to `/cost-estimation-guide` when cost planning is discussed.
- One quote CTA and one WhatsApp support CTA.

## Measurement

Review each new page after 30, 60 and 90 days using:

- Search Console impressions, clicks, CTR and average position.
- GA4 or first-party guide interactions.
- Quote, WhatsApp, phone and email conversions from that landing page.
- Questions customers ask after reading the page.

Refresh or expand pages based on real Search Console queries and customer questions.
